# Store assets

Extension images come from the actual extension UI; recorded demonstration data
is labeled. A showcase recording must not include customer browsing history,
credentials, invented successful actions or fabricated protection claims.

`native_capture.rs` is a test-only child module for the Windows WindowApp in the
PR58 source. It renders that exact UI offscreen using egui_kittest and owner-
approved, recorded readings with private identifiers redacted. It creates no
OS windows, starts no daemon, executes no action, and changes no installed app
or user settings. These are development previews until the pictured source is
in the reviewed release. Do not substitute Chrome or Mac screenshots for the
Windows app.

Microsoft's EXE/MSI listing currently documents screenshots and logos, not a
trailer slot. Verify the actual listing fields before uploading a video. Chrome
accepts an optional YouTube link; creating a local MP4 does not publish it.
