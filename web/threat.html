What it watches

Each engine is the official, unmodified open-source project. ThreatWarden reads what they find and puts it in one place.

HOST

Wazuh intrusion detection

Log analysis, file integrity monitoring, vulnerable software and known attack patterns on this computer, scored by Wazuh's own rules.

FILES

ClamAV malware scanning

Scans downloads and the places malware likes to hide against a signature database that updates on its own.

NETWORK

Suricata network intrusion detection

Inspects traffic for exploit attempts, command-and-control callbacks and known-bad hosts.

TRAFFIC

ntopng network visibility

Shows what is talking to what: which apps use the network, how much, and with whom.

One status, in plain words

Every finding rolls up into one level, with a headline and what to do about it. Silence from a disconnected agent never counts as all-clear.

ClearNothing needs you.
WatchWorth a look, nothing urgent. Also shown when an engine stops reporting.
AlertAct now. High-severity detections (Wazuh level 12 and up).
OffNot set up or not reachable, and which one.
OBSERVES

Read-only by design

ThreatWarden never quarantines, blocks or kills anything. Any automatic response stays with the security tools themselves, configured by you.

PROTECTED

Untouchable by RamWarden

The security agents are structurally protected: RamWarden's memory warden can never freeze or close them, whatever the watchlist says.

PRIVATE

Credentials stay encrypted

Connections to the security servers must use HTTPS with certificate checks. There is no switch to turn that off.

Questions

Does it replace my antivirus?

No. It adds visibility on top of what you already run, and it never turns your existing protection off. RamWarden never weakens security settings to free memory.

Are Wazuh, ClamAV, Suricata and ntopng modified?

No. ThreatWarden uses the official, unmodified projects from their own packages and reads what they report. They are separate open-source projects with their own licences; RamWarden is not affiliated with them.

What does the hosted version send to your servers?

The security events your engines produce, so the hosted manager can analyse them and send the results back. Self-hosting keeps all of it on your own server.

Will it slow my computer down?

The heavy parts (the Wazuh manager and indexer) run on the server, not on your computer: hosted, on ours; self-hosted, on yours. RamWarden's memory warden keeps an eye on the rest.
