# Chrome Web Store draft: RamWarden 0.3.0

Status: upload-ready package, not a public release. The Chrome extensions gallery blocks scripted access; the publisher must upload through their dashboard. Keep the item in draft until production website/account checkout and hosted security deployment have been verified.

## Listing copy

**Name:** RamWarden

**Short description:** Free, reversible idle-tab cleanup, with optional desktop RAM and security reports.

**Detailed description:**

Keep your work. Give idle tabs a rest.

RamWarden Lite offers free browser cleanup. Turn it on, choose how many recent tabs to keep, and it unloads eligible tabs after an hour of inactivity. Tabs stay in the tab strip and reload when selected. Active, pinned, audible, private and protected work tabs are excluded. It does not close tabs or claim a measured amount of RAM saved.

Connect the optional RamWarden desktop app to see measured RAM use and coordinate cleanup. The ThreatWarden tab shows the connected desktop daemon's security status, engine health and recent rule alerts. A rule alert is not confirmed malware. Engines that are unavailable or planned are labeled accordingly. The extension itself is not antivirus software.

Optional paid desktop plans are managed on the Warden website. Users can sign in with email, wallet or GitHub. Wallet sign-in is not a payment. Purchases use a separate, explicit checkout; network and destination verification belong there. Lite browser cleanup does not require buying a plan.

## Permission justification

- `tabs`: read tab identity/activity and unload selected eligible idle tabs; maintain the optional reopen history from the connected daemon.
- `storage`: retain local settings, activity times, safety feedback and reopen records.
- `alarms`: scheduled cleanup when Lite is enabled and bounded companion/status checks.
- Localhost host permissions: communicate with the optional local desktop daemon.
- Optional HTTP host permission: only requested after a user explicitly selects another daemon host, such as an authorized device on their own tailnet.
- HTTP/HTTPS content-script matches: observe interaction timestamps and whether work may be in progress so active editing is protected. No form values or page bodies are collected by this activity script.

The publisher must disclose browsing activity/URLs/titles and interaction signals accurately in Chrome's privacy questionnaire. They are processed locally and can be sent to the user's configured desktop daemon; optional hosted analysis follows desktop settings and consent. Account and payment data belong to the separately authenticated website. Do not claim the product collects no browsing data. No API key, wallet seed, merchant secret or provider credential belongs in the ZIP. There is no remote executable code.
